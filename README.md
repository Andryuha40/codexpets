# Codex Pets

[English](README.en.md) · Русский

Коллекция анимированных персонажей для настольного Codex. **Tikinson** — первый персонаж, созданный **Andrey / [Andryuha40](https://github.com/Andryuha40)**: любопытный напарник, который любит всё перепроверять.

![Tikinson](media/tikinson-idle.gif)

## Скачать и установить

[Скачать Tikinson v1.0.0](downloads/tikinson-v1.0.0.zip?raw=true) · [Инструкция установки](docs/installation.ru.md) · [Контрольные суммы](SHA256SUMS)

В комплекте: 9 анимационных состояний, 16 направлений взгляда, прозрачный атлас Codex pet v2. Это ресурс персонажа; события и поведение определяет приложение Codex. Проверено на Windows с Codex 26.915.4065.0; совместимость с будущими версиями может меняться.

## Условия использования

Личное некоммерческое использование с указанием автора. Изменение персонажа, коммерческое использование и отдельная перепубликация файлов требуют предварительного письменного разрешения автора. [Полная лицензия RU/EN](LICENSE.md). Это не лицензия свободного ПО. Для согласования откройте Issue в этом репозитории.

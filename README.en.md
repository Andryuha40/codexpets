# Codex Pets

English · [Русский](README.md)

A collection of animated companions for the Codex desktop app. **Tikinson** is the first character, created by **Andrey / [Andryuha40](https://github.com/Andryuha40)**: a curious companion who likes to double-check everything.

![Tikinson](media/tikinson-idle.gif)

## Download and install

[Download Tikinson v1.0.0](downloads/tikinson-v1.0.0.zip?raw=true) · [Installation guide](docs/installation.en.md) · [Checksums](SHA256SUMS)

Includes 9 animation states, 16 gaze directions and a transparent Codex pet v2 atlas. This is a character asset; the Codex application controls events and behavior. Verified on Windows with Codex 26.915.4065.0; future compatibility may change.

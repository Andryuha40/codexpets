# Codex Pets

[![Telegram: Tikinson Games](https://img.shields.io/badge/Telegram-Tikinson%20Games-26A5E4?logo=telegram&logoColor=white)](https://t.me/tikinsongames)

**Artist Tikinson — [Tikinson Games on Telegram](https://t.me/tikinsongames).** The character is based on his drawings: Tikinson is the artist’s nickname, and the character is his self-portrait.

English · [Русский](README.md)

A collection of animated companions for the Codex desktop app. **Tikinson** is the collection’s first pet, adapted for Codex by **Andrey / [Andryuha40](https://github.com/Andryuha40)**: a curious companion who likes to double-check everything.

![Tikinson](media/tikinson-idle.gif)

**Tikinson for Claude Code:** [claude-pets](https://github.com/Andryuha40/claude-pets) is a mod by Andryuha40 featuring the same character. This repository contains the Codex pet; the Claude Code mod is developed separately.

## Download and install

[Download Tikinson v1.0.0](downloads/tikinson-v1.0.0.zip?raw=true) · [Installation guide](docs/installation.en.md) · [Checksums](SHA256SUMS)

Includes 9 animation states, 16 gaze directions and a transparent Codex pet v2 atlas. This is a character asset; the Codex application controls events and behavior. Verified on Windows with Codex 26.915.4065.0; future compatibility may change.

# Установка Tikinson

[English](installation.en.md)

Проверено на Windows, Codex 26.915.4065.0 с поддержкой пользовательских питомцев v2. Архив не содержит приложение Codex или исполняемые установщики.

1. Скачайте `downloads/tikinson-v1.0.0.zip` из репозитория и распакуйте.
2. Если Tikinson уже установлен, сохраните резервную копию его папки.
3. В адресной строке Проводника откройте `%USERPROFILE%\.codex\pets`. Создайте папку `pets`, если её нет. При собственном `CODEX_HOME` используйте его подпапку `pets`.
4. Скопируйте папку `tikinson` из архива. Должны получиться `.codex/pets/tikinson/pet.json` и `.codex/pets/tikinson/spritesheet.webp`, без лишней вложенной папки.
5. Перезапустите Codex и выберите Tikinson в меню питомцев. Сохраните лицензию и сведения об авторе.

Для удаления выберите другого питомца и удалите только папку `tikinson`. Для обновления замените её содержимое после резервного копирования.

На других ОС установка не проверена. Приветствие и другие эмоции запускает Codex; приветствие не гарантировано при каждом появлении питомца. Если персонаж не виден, проверьте поддержку формата v2, путь и целостность файлов. Архив содержит контрольную сумму атласа; внешний `SHA256SUMS` также содержит сумму ZIP. В PowerShell: `Get-FileHash -Algorithm SHA256 <путь-к-файлу>`.

# Участие / Contributing

## Русский

Предлагайте оригинальных персонажей через Issue, затем Pull Request. Укажите автора, происхождение графики, использование ИИ, лицензию и право разрешить публикацию. Для нового персонажа добавьте отдельную папку `characters/<id>`, запись в каталоге, инструкции RU/EN и превью. Условия Tikinson не распространяются автоматически на персонажей других авторов. Публикация чужих материалов без прав не принимается. Изменения Tikinson требуют разрешения автора до подготовки производной графики. Исправления документации обсуждайте в Issue; присылая исправление, разрешаете владельцу включить его в документацию проекта. Для нового персонажа условия публикации согласуются отдельно. Никогда не присылайте ключи, пароли или файлы настроек.

## English

Propose original characters in an Issue, then a Pull Request. Identify the author, artwork origin, AI involvement, license and your authority to permit publication. Add a separate `characters/<id>` folder, catalog entry, RU/EN instructions and preview. Tikinson's terms do not automatically apply to other authors' characters. Unauthorized third-party materials are not accepted. Tikinson changes require author permission before preparing derivative artwork. Discuss documentation fixes in an Issue; by submitting a fix, you permit the owner to include it in project documentation. Publication terms for new characters are agreed separately. Never submit keys, passwords or configuration files.
